FAQ

Is TopicSplit really free?

Yes. MIT licensed, forever free. No premium tier, no feature gates. If it saves you time, a $1 tip keeps the tools coming.

Does my text leave my browser?

Never. Everything runs client-side in a single HTML file. No server, no API key, no tracking.

What algorithms does it use?

Lexical cohesion — computes content-word overlap between adjacent sentences, identifies statistical breakpoints, and groups accordingly. No ML model, no network call.

Can I use the output in Obsidian/Logseq/Notion?

Absolutely. Output is clean markdown with ### Topic N headers that paste right into any tool.
