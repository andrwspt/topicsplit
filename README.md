## Why TopicSplit?

You have an article, transcript, or meeting notes. You need to split it into clean topic segments for your PKM system. Manual splitting is tedious and subjective.

TopicSplit uses **lexical cohesion analysis** to find natural topic boundaries — the same words appearing together signal a topic shift. No AI, no server, no tracking. Just math in your browser.

3. Adjust the sensitivity slider (higher = more splits)
4. Click "Split into topics"
5. Copy the markdown or download as `.md`

## FAQ

**Is it really free?**
Yes. MIT licensed, no paywall, no premium tier. Forever.

**Does my data leave my browser?**
No. Everything runs client-side. No server, no API key, no tracking.

**How is this different from AI summarizers?**
AI summarizers rewrite your text. TopicSplit finds natural topic boundaries and keeps your original words — perfect for atomic notes and PKM workflows.

**Can I use the splits commercially?**
Yes. MIT license means you can use the output however you want.

**What if it splits wrong?**
Adjust the sensitivity slider. Higher values = more aggressive splitting. Lower values = fewer, longer segments.
