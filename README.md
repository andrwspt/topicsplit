# TopicSplit

A tiny, **offline** tool that groups pasted text into topic segments by lexical cohesion — no server, no API key, no tracking.

**👉 Live demo:** https://andrwspt.github.io/topicsplit/

## What's new in v1.6

- **Shareable Digest** — one-click summary card with attribution link
- **Challenge a Friend** — pre-written message to send to note-taking friends
- **Embeddable Widget** — drop TopicSplit on any site with a single iframe
- **Embeddable Badge** — "Powered by TopicSplit" badge for your site

## Embed on your site

```html
<iframe src="https://andrwspt.github.io/topicsplit/" width="100%" height="500" frameborder="0"></iframe>
```

## Built for

- Obsidian users breaking down articles into atomic notes
- Logseq users splitting journal entries or research
- Notion users organizing meeting notes
- Researchers segmenting interview transcripts
- Writers structuring long-form content
