What "semantic splitting" actually means

Most people hear "semantic" and think AI/ML. TopicSplit uses lexical cohesion — a simpler, faster, more predictable approach:

  1. Extract content words from each sentence (skip stopwords like "the", "and", "is")
  2. Measure overlap between adjacent sentences (shared vocabulary = same topic)
  3. Find breakpoints where overlap drops significantly (topic shift)
  4. Group sentences between breakpoints into segments

No neural network. No API call. No server. Just ~130 lines of JavaScript that runs in your browser.
